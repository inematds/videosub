Qué es

Un estudio local y verificable

VideoSub transforma un tema breve o contenido completo en video vertical, cuadrado u horizontal, y mantiene al operador al control del resultado.

🧭 Etapas visibles

El guion, la voz, la imagen, el movimiento, los subtítulos y el render aparecen por separado para su revisión.

🔌 Proveedores reales

Codex OAuth crea el guion, ElevenLabs produce la voz y Agnes genera imágenes y videos.

🏠 Ejecución local

La interfaz y la API se ejecutan en la máquina, con SQLite para los proyectos y FFmpeg para el montaje final.

Cómo funciona

Una línea de producción en siete pasos

Cada resultado se conserva en el proyecto y puede revisarse antes de la siguiente operación.

Contenido→Guion→Voz→Imágenes→Animación→Subtítulos→MP4
Requisitos previos

Lo necesario para ejecutar

La aplicación usa herramientas locales y credenciales configuradas en un archivo sin seguimiento de versiones.

Node.js y pnpm

Node.js 22 o superior y pnpm 10.

node --version
pnpm --version

FFmpeg

FFmpeg y FFprobe disponibles en el PATH, incluido el filtro subtitles.

ffmpeg -version
ffprobe -version

Proveedores

Codex autenticado y claves de Agnes y ElevenLabs en el entorno local.

codex login status
# configura apps/server/.env
Guía de uso · paso a paso

Ejecuta y produce el primer video

Los comandos de abajo son los mismos que se usan en la versión local del proyecto.

1

Instala las dependencias

En la raíz del repositorio, instala el workspace.

pnpm install --frozen-lockfile
2

Crea la configuración local

Copia la plantilla y completa las credenciales sin incluir el archivo en el control de versiones.

cp .env.example apps/server/.env
nano apps/server/.env
3

Compila e inicia

El script crea el build cuando es necesario y publica la interfaz en el puerto 3333.

pnpm build
./start.sh
# abre http://localhost:3333
4

Crea un proyecto

Indica el tema o el contenido, elige el formato y el estilo, y genera el guion.

Tema: explique o que é AGI
Formato: 9:16
Estilo: editorial cinematográfico
5

Valida cada etapa

Genera voz, imágenes y animaciones; revisa las escenas y solo después crea subtítulos y renderiza.

# flujo en la interfaz
Roteiro → Voz → Imagens → Animar → Legendas → Renderizar
6

Actualiza o cierra

Usa los scripts operativos incluidos en el repositorio.

./atualiza.sh  # valida, compila y reinicia
./stop.sh      # cierra el servidor
